# **Overview**

An end-to-end production-grade DevSecOps pipeline that integrates secure coding, vulnerability scanning, container image hardening, artifact management, and automated Kubernetes deployment.
The goal is to show how real companies implement secure CI/CD using a combination of:

* Jenkins
* SonarQube (SAST + coverage)
* Trivy (SCA + image scanning)
* AWS ECR
* Amazon EKS
* Kubernetes YAML manifests
* IAM + RBAC for least-privilege deployments
